# 🍩 Que Rollo - Aplicación móvil de repostería

## 📌 Descripción

Que Rollo es una aplicación móvil de tipo e-commerce desarrollada en React Native con Expo, que permite a los usuarios explorar, seleccionar y comprar productos de repostería artesanal como rollos de canela y galletas.

La aplicación ofrece una experiencia de compra intuitiva, permitiendo gestionar el carrito, realizar pedidos y consultar el historial de compras.

---

## 🎯 Objetivo

Desarrollar una aplicación móvil que digitalice el proceso de ventas de un emprendimiento de repostería, mejorando la experiencia del usuario y la organización de pedidos.

---

## 👥 Usuarios

* Clientes interesados en comprar productos de repostería
* Personas entre 14 y 40 años
* Usuarios de dispositivos móviles

---

## ⚙️ Tecnologías utilizadas

* React Native
* Expo
* Firebase Authentication
* Cloud Firestore
* JavaScript

---

## 🧩 Funcionalidades principales

* Registro de usuario
* Inicio de sesión
* Visualización de catálogo de productos
* Detalle de productos
* Carrito de compras
* Proceso de compra
* Generación de factura
* Historial de compras
* Configuración de la aplicación

---

## 🏗️ Arquitectura del sistema

El sistema sigue una arquitectura cliente-servidor basada en servicios en la nube:

* Aplicación móvil (React Native)
* Lógica de aplicación
* Firebase (Authentication + Firestore)

---

## 🚀 Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/ccastanom/Progra-Movil-React-Native.git
```

2. Instalar dependencias:

```bash
npm install
```

3. Ejecutar la aplicación:

```bash
npx expo start
```

---

## 📱 Ejecución

* Usar Expo Go en el celular
* Ejecutar en emulador Android
